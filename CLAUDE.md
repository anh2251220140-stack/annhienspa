# Kiến trúc hiện tại

An Nhiên Spa là bộ giao diện HTML + CSS + JavaScript thuần, không sử dụng
React, TypeScript, Vite, Tailwind, npm hoặc Node.js để hiển thị.

Đọc và tuân thủ `AGENTS.md`; xem `README.md` để biết cách mở các trang
và chuẩn bị tích hợp Django Templates/static.

Trang HTML nằm ở thư mục gốc; tài nguyên nằm trong `css/`, `js/`, `images/`.
Không tái tạo scaffold frontend. Giữ nguyên thiết kế luxury spa, nội dung
tiếng Việt, responsive, ảnh và tương tác mẫu khi dọn công cụ.
